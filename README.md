# Rowan Mercer Lite : free one-page template for developer portfolios

A single-file HTML template with a dark, brutalist register: giant
sentence-case display type, lowercase monospace as the system voice, heavy
rules, one accent colour. Smooth scrolling (Lenis) and scroll-triggered
animation. No build step, no frameworks : open `index.html` and edit.

**Live demo:** https://mercer-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html` : your name, role, city, projects, testimonial, email.
2. Replace the photos in `img/` with your own product screenshots (keep the filenames, or update the `src` paths).
3. Update the `mailto:` links (there are three) to your own email address.
4. Upload anywhere : it's static files. Vercel, Netlify and GitHub Pages host it free.
